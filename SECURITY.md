# Security Policy / Kebijakan Keamanan

## Supported versions / Versi yang didukung

Only the latest release and `main` receive fixes.
Hanya rilis terbaru dan `main` yang mendapat perbaikan.

## Reporting a vulnerability / Melaporkan kerentanan

Please **do not** open a public issue. Use GitHub's private
[Report a vulnerability](https://github.com/pawang-ai/markdown-badges-collection/security/advisories/new)
form. Include what you found, how to reproduce it and the affected commit.
We aim to respond within 5 business days.

Jangan membuat issue publik. Gunakan form privat
[Report a vulnerability](https://github.com/pawang-ai/markdown-badges-collection/security/advisories/new)
di GitHub. Sertakan temuanmu, langkah reproduksi, dan commit yang terdampak.
Kami berusaha merespons dalam 5 hari kerja.

## Scope / Cakupan

This repository ships static data, a small Python generator and a static website. Reports about the generator, the workflows or the site (for example XSS in `docs/index.html`) are in scope. Rendering problems on Shields.io or brand-logo issues are not; report those upstream.
