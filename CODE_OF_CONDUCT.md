# Code of Conduct / Kode Etik

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Proyek ini mengikuti [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short / Singkatnya:

- Be respectful and welcoming to everyone. / Hormati dan sambut semua orang.
- Give and accept constructive feedback gracefully. / Beri dan terima masukan dengan baik.
- No harassment, discrimination, or personal attacks. / Tidak ada pelecehan, diskriminasi, atau serangan pribadi.

## Reporting / Pelaporan

Report unacceptable behavior privately to the maintainers through the [pawang-ai](https://github.com/pawang-ai) organization on GitHub (for example by messaging an organization owner). Maintainers will review every report promptly and fairly, and keep the reporter's identity confidential.

Laporkan perilaku yang tidak pantas secara privat kepada maintainer melalui organisasi [pawang-ai](https://github.com/pawang-ai) di GitHub (misalnya dengan mengirim pesan ke owner organisasi). Maintainer akan meninjau setiap laporan dengan cepat dan adil, serta merahasiakan identitas pelapor.
